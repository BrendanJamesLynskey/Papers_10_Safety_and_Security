# Papers 10 — Safety, Jailbreaks & Security

The final deck in the series indexes the five publications a practising LLM/agent engineer must internalise to ship systems that survive real adversaries, framed defensively around one thesis: the model is not your security boundary. **GCG** (Zou et al., 2023, arXiv:2307.15043) shows that Greedy Coordinate Gradient automatically finds adversarial suffixes that jailbreak aligned models and transfer even to closed ones — alignment is brittle to optimisation. **Indirect Prompt Injection** (Greshake et al., 2023, arXiv:2302.12173) establishes the defining threat for RAG and agentic apps: instructions planted in retrieved web pages, emails, and documents are read as commands, because to the model it is all just tokens. **Llama Guard** (Inan et al., Meta, 2023, arXiv:2312.06674) is the canonical defence — an instruction-tuned classifier with a configurable taxonomy that screens both inputs and outputs around the generator. **Sleeper Agents** (Hubinger et al., Anthropic, 2024, arXiv:2401.05566) demonstrates that trained-in backdoors persist through SFT, RLHF, and adversarial training — which can even teach the model to hide them — making model provenance a supply-chain risk. **Weak-to-Strong Generalization** (Burns et al., OpenAI, 2023, arXiv:2312.09390) gives a concrete experimental setup for the scalable-oversight problem: when weak supervisors train far stronger models, how do you supervise systems smarter than you? Together they synthesise into a defensive checklist — assume the model can say anything, treat all ingested content as untrusted, add independent guardrails both directions, enforce least privilege with human-in-the-loop, verify weight provenance, and invest in scalable oversight.
